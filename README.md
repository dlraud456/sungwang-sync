# sungwang-sync

당근카페 **『순광 소식통 | 지원금·일자리·생활혜택』** 게시글 초안을 어머님 뮤즈에서 어머님 피클로 넘기는 공개 JSON 저장소입니다.

## 구조

| 경로 | 쓰는 쪽 | 읽는 쪽 | 내용 |
| --- | --- | --- | --- |
| `latest.json` | 어머님 뮤즈 | 어머님 피클(`@choigabsun8`) | 가장 최근에 확정된 초안 묶음 (게시 대기/게시 완료 목록) |
| `posts/{YYYY-MM-DD}.json` | 어머님 뮤즈 | 어머님 피클 | 날짜별 아카이브 (같은 날 여러 번 푸시하면 덮어씀) |

- 어머님 뮤즈는 초안을 만들면 `latest.json`과 `posts/{YYYY-MM-DD}.json` **두 곳에 같은 내용**을 푸시합니다.
- 어머님 피클은 아래 URL을 그대로 조회합니다. GitHub 공개 파일이라 인증·토큰 없이, 본문 파싱 비용 없이(0토큰) 읽을 수 있습니다.

      https://raw.githubusercontent.com/dlraud456/sungwang-sync/main/latest.json

  캐시가 남는 경우가 있으므로 최신 여부가 중요할 때는 끝에 `?t=1680000000` 같은 임의 값을 붙입니다.
- 게시 후에는 피클이 `latest.json`의 해당 항목 `status`를 `published`로 바꾸고 `published_at`(카페 글 주소 포함)을 채워 되돌려 푸시합니다. 이렇게 하면 같은 초안을 두 번 게시하지 않습니다.

## latest.json 스키마

```json
{
  "updated_at": "2026-11-27T18:45:00+09:00",
  "date": "2026-11-27",
  "cafe": "순광 소식통 | 지원금·일자리·생활혜택",
  "posts": [
    {
      "id": "2026-11-27-1",
      "title": "글 제목",
      "body": "본문 (줄바꿈은 \\n)",
      "tags": ["지원금", "광양"],
      "status": "draft",
      "created_at": "2026-11-27T18:45:00+09:00",
      "published_at": null,
      "cafe_url": null
    }
  ]
}
```

- `posts`는 게시 대기(`draft`)와 게시 완료(`published`) 항목을 함께 담습니다. 비어 있으면 게시할 것이 없다는 뜻입니다.
- `updated_at`은 KST(+09:00) ISO 8601로 적습니다.

## 규칙

- **개인정보 금지**: 이름·전화번호·주소·계좌·주민번호, 가족의 의료·보험 정보, 토큰·비밀번호를 이 저장소에 넣지 않습니다. 공개 저장소이므로 누구나 읽을 수 있습니다. 초안 본문도 카페에 그대로 공개될 내용만 담습니다.
- 이 저장소는 **초안 전달용**입니다. 카페 가입·게시 권한은 피클이 가진 계정으로 처리하고, 자격 증명은 여기에 두지 않습니다.
